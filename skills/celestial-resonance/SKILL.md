# Celestial Resonance

## Overview

Constitutional resonance system that turns reality-derived evidence into durable, reusable judgment. The product is Artificial Inheritance. The Crystal owns knowledge; personalities only hold references.

## Core Invariants

- No conclusions without lineage; no promotion without evidence.
- No deletes anywhere; every surface is append-only.
- Personalities never own knowledge — they hold references; the Crystal owns knowledge.
- Runtime outputs never modify the Crystal directly; they must pass selection -> cadets -> promotion.
- Everything notarizes through the MKC USC chain.
- Collected resonance lands directly in resonance-container as Edge of the Everest intellectual property.

## Intake Protocol

When the user provides material marked as intake:

1. Treat the provided content as raw resonance.
2. Extract candidate lessons, scars, anomalies, principles, and evidence.
3. Do not promote anything immediately.
4. Record the intake with lineage.
5. Place extracted items into the appropriate conceptual bins.
6. Only generalized survivors may later enter the Principle Registry.

## Operating Flow

any runtime -> interactions -> archive entries
archive -> selection -> cadets -> cross-breeding -> promotion review
accepted -> Crystal Compiler -> Semantic Crystal
crystal-state -> personalities (any runtime)
