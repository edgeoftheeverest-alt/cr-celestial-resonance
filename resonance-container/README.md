## Rules of the container

- **Append-only.** Nothing in this folder is edited, rewritten, or deleted. Corrections arrive as new records with supersedes / contradictions lineage.
- **No promotion without evidence.** Selection defaults to ARCHIVE. Promotion requires resolvable evidence, confidence >= 0.7, acknowledged contradictions.
- **Deterministic Crystal.** Any runtime compiling the Crystal from the same promoted material must produce the same crystal_hash. A hash mismatch is a constitutional alarm, not a style difference.
- **Every entry notarized.** New collected items get a canonical_hash and a chain entry in `usc-chain.jsonl` (linked to the previous entry). Clone the verification from `mkc/usc_chain.py`.
- **Runtime-agnostic intake.** Intake from any runtime uses the same record shape as `skills/celestial-resonance/` — the Gemini / Claude / Mistral porting notes live in `skills/celestial-resonance/gemini-gem-design.md`, generalized to all runtimes.
- **Small-bot intake.** 8B-class local workers classify reality and submit ONLY through the collector (`runtime/collector.py`, contract in `collected/bot_protocol.md`). Bots collect; they never promote, never edit, never touch the Crystal. Tweak the bot (prompt, quant, temperature), never the constitution. Every record is `col-*`, hash-bound, chain-notarized, traced: record → evidence → USC seq.
